# Wymagania dla kandydata przed rozmową techniczną

Tekst do wysłania kandydatowi przed rozmową (I-4, D-019, D-020). Wersja polska i angielska.
**Przed wysłaniem przejrzyj i dopasuj treść** — to wiadomość zewnętrzna, wygenerowana przy pomocy AI.

Zadania rozwiązuje się domyślnie w przeglądarce. Własne IDE jest opcją: kto nie spełnia wymagań
albo nie chce nic instalować, pracuje w przeglądarce.

## Wersja polska

Temat: Rozmowa techniczna — przygotowanie środowiska

Dzień dobry,

podczas rozmowy rozwiążesz krótkie zadania programistyczne w Javie albo w TypeScript (wybór należy
do Ciebie), udostępniając swój ekran.

**Wariant domyślny — przeglądarka.** Dostaniesz link do zadania. Wystarczy aktualna przeglądarka
(Chrome, Edge albo Firefox) i dostęp do internetu. Niczego nie trzeba instalować ani zakładać konta.

**Wariant opcjonalny — własne IDE.** Jeśli wolisz pracować w IntelliJ IDEA albo VS Code, możesz
pobrać zadanie jako gotowy projekt. Sprawdź wtedy przed rozmową, że masz:

- Java: JDK 17 lub nowszy (`java -version`). Gradle nie jest potrzebny, projekt ma własny wrapper.
- TypeScript: Node.js 20 lub nowszy (`node --version`) oraz npm.
- Dostęp do internetu bez blokad dla Maven Central (Java) albo rejestru npm (TypeScript). Przy
  pierwszym uruchomieniu projekt pobiera zależności.

Jeśli projekt nie uruchomi się u Ciebie w kilka minut, wracamy do przeglądarki — nie wpływa to na
ocenę.

Pozdrawiam

## English version

Subject: Technical interview — environment setup

Hello,

during the interview you will solve short programming tasks in Java or TypeScript (your choice)
while sharing your screen.

**Default option — browser.** You will get a link to the task. All you need is an up-to-date
browser (Chrome, Edge or Firefox) and internet access. There is nothing to install and no account
to create.

**Optional — your own IDE.** If you prefer IntelliJ IDEA or VS Code, you can download the task as a
ready-made project. In that case please check before the interview that you have:

- Java: JDK 17 or newer (`java -version`). You do not need Gradle; the project ships with a wrapper.
- TypeScript: Node.js 20 or newer (`node --version`) and npm.
- Internet access that does not block Maven Central (Java) or the npm registry (TypeScript). The
  project downloads its dependencies on first run.

If the project does not start on your machine within a few minutes, we switch back to the browser.
This does not affect your assessment.

Best regards
